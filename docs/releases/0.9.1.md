# Sub Buddy 0.9.1

新增默认关闭的子智能体协作：适合长视频，消耗更多额度；动态分块、最多两个子任务接续翻译，开启时自动选择最低可用推理强度，关闭时恢复 none。改进字幕完整性校验与保存，格式错误仅补翻失败条目，最多自动再试两次，原始时间轴保持不变。

Added opt-in subagent collaboration for long videos with higher allowance usage: dynamically balanced tasks, up to two workers, lowest available reasoning when enabled and none when disabled. Improved validation and checkpoints; retry only invalid or missing cues up to twice while preserving source timestamps.
