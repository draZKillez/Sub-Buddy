# Sub Buddy 0.9.1-beta.1 (25)

本地测试版，不发布到 GitHub 正式更新频道。macOS 14+，Intel 与 Apple Silicon 通用。

## 本次变更

- 默认每批 200 条；Codex 自动模式默认最多同时 2 批，可选 1 批顺序执行。Apple Translation 仍顺序运行。
- 每批保留前后各最多 50 条原文上下文；同一轮共享已确认术语表，按批次顺序合并新术语。并发中的新译名不能即时相互共享，仍可能存在译名差异。
- 官方 `codex exec --output-schema` 约束字段、类型和可用 ID。应用继续验证 ID、重复/缺失、非空正文、原文对应、换行和标签。
- 有效条目持久保存；仅补翻未通过条目，最多两轮补翻（100/50 条上限）。无法解析的完整 JSON 不会猜测性截取；无法确认有效的条目仍需补翻。
- 按原始 ID 与时间轴合成 SRT，导出前重新解析，校验通过才写入。空结果不能覆盖已有文件。
- 限流、额度、登录或服务错误终止当前并发组，不启动下一组；保存已通过条目，等待用户处理后重试。不切换账号、模型或 API。单请求 15 分钟超时，取消会终止两路请求。
- 修复自动回退误选 Forced 轨道，以及修改目标语言重置手动轨道选择的问题。
- 新增控制项与进度文字提供十种界面语言。

## 条款与隐私（2026-09-06 核对）

[官方非交互文档](https://learn.chatgpt.com/docs/non-interactive-mode)明确支持脚本调用、Schema 输出与复用 CLI 登录；[使用条款](https://openai.com/policies/row-terms-of-use/)禁止绕过限流、共享账号、侵犯他人权利，并包含自动提取数据或输出的限制。

本实现采用官方文档所述的 CLI 自动化入口，不抓取网页、不调用内部接口、不读取或复制 auth.json、不汇集多人账号。每个用户使用本人登录与共享套餐额度，仅处理自己有权提供的字幕。

这属于基于公开文档的工程判断，不是 OpenAI 对本软件或字幕并发场景的审核批准，也不是法律意见或“不会封号”的保证。并发没有额外额度，不绕过任何服务限制。若需要服务方对具体用途的书面确认，应联系 OpenAI 支持。

## 如何试用

1. 先退出旧版并保留旧版安装包。打开 DMG，把 Sub Buddy 拖到 Applications 替换。
2. 选择完整对白字幕轨道（不是仅包含路牌、外语对白的 Forced 轨道），确认原文与目标语言。
3. 自动模式保持 Luna、无额外推理、200 条、2 批并发；可切换为 1 批作对照。
4. 检查进度中的活动批次、已完成字幕数；中途取消后再次开始，已保存的有效条目应恢复。
5. 输出为视频旁的 SRT；原视频不会修改。播放器未自动加载时，手动选择该 SRT。

Beta 使用与正式版相同的应用标识和进度目录；不要同时运行两版。DMG 为本地 ad-hoc 签名，未做 Apple 公证。

## English summary

Local-only beta: 200 cues per batch and up to two concurrent official Codex CLI requests, with a sequential option. Adds output Schema constraints, local validation, targeted bounded retries, serialized checkpoints, and SRT round-trip validation. Forced-only subtitle fallback and target-language track resets are fixed. macOS 14+, Universal Intel/Apple Silicon.

Uses the user's own official CLI login; no API fallback, credential copying, browser scraping or quota circumvention. Service/quota errors pause work. Public documentation supports CLI automation but does not constitute approval of this app or a guarantee against account restrictions. Only submit content you have rights to use. Keep a stable installer; do not run stable and beta simultaneously. Locally ad-hoc signed, not notarized.
