# Sub Buddy 0.9.1-beta.2 (26)

本地测试版，不推送 GitHub，不修改正式版更新源。

## 本次测试什么

- 新增「官方子智能体（Beta）」模式：一轮最多 750 条，主任务负责委派及 150 条翻译，两个子任务各 300 条。尾段按实际数量缩小，150 条以内及补翻请求直接处理。
- 每轮只启动一个官方 `codex exec` 会话，最多两个直接子任务；不会同时启动第二轮，也不使用其他账户、API Key 或 API 作为后备。
- 子任务结果从官方 JSONL 完成事件直接收集，主任务无需重抄 600 条译文。逐份本地校验、保存；整轮结束后只补翻缺失或无效的条目。
- 保留普通 200 条分块、顺序／最多两批并发，方便手动比较；手动翻译、Apple Translation 等现有功能不变。
- 修复流式 UTF-8 字符被拆开时可能损坏 JSON，以及进程退出时最后一段输出未发送给流式监听器的问题。

## 如何测试

1. 退出已运行的 Sub Buddy，保留正式版备份，再从本 DMG 安装测试版。
2. 选择影片和完整字幕轨道，在翻译设置选择 Codex，开启「官方子智能体（Beta）」。
3. 检查模型、源语言、目标语言及输出位置，再开始。默认模型仍为 Luna。
4. 建议先用一集短剧测试，记录用时、有效条目数和错误；需要对比时关闭子智能体开关，选择普通分块。

请勿让正式版与测试版同时处理同一影片；两者共用本机登录和进度存储。已有字幕覆盖仍需确认，视频不会因导出 SRT 而被修改。

## 必须了解的限制

- 委派不是确定性的函数调用。若模型没有创建所需子任务、子任务标记错误或事件协议不兼容，应用会停止并显示错误，不会假装完成或悄悄改成其他模式。
- 为提高委派可靠性，本测试模式**主任务和子任务固定使用 low 推理**，界面明确显示。实测 Luna 的主任务 `none` 有时直接跳过委派，子任务显式 `none` 则被当前 CLI 拒绝。普通模式仍可使用 `none`。
- `--output-schema` 约束主任务输出，**不能声称它同时强制约束每个子任务**。所有结果仍需本地检查 ID、原文绑定、空文本、标签与换行；模型翻译质量和逐句语义不能靠 JSON Schema 保证。
- 委派与上下文传递有额外耗时、额度消耗，不保证比普通分块更快。新模式没有可复用的整体耗时基准，因此不套用旧模式的整体 ETA；仍显示累计用时、已处理条目与阶段进度。
- 遇到额度、认证、模型或服务错误会暂停；不自动切换模型、不绕过限额。每轮最长 15 分钟，事件和输出大小也有上限。
- 仅在本机 Codex CLI 0.153.4 验证事件协议；旧版 CLI 可能需要更新。App 自身不读取、复制或解析 `auth.json`，不使用网页 Cookie 或非官方网页接口。
- macOS 14+，Universal（Intel / Apple Silicon）；本地 ad-hoc 签名，未做 Apple 公证。离线并不等于可使用 Codex：该模式仍需要官方服务和账户额度。

## 本地验证记录

- 回归测试 157 项：151 项通过，6 项需环境显式启用的集成测试跳过，无失败。
- 独立启用的真实子智能体测试：5 条英文→日文通过；完整 750 条英文→日文通过，154.865 秒。事件核对主任务 1–150、两个子任务分别 151–450 和 451–750，源文、数量、格式全部通过校验。
- 上述 750 条是简单、重复模式的原创合成文本，用于测试分工和数据完整性，**不是电影翻译性能基准或语义质量测试**，不可推断真实电影也需相同时间。
- 调试中 `none` 主任务曾跳过委派，已在子智能体模式中改为显式 `low`。一次 750 条测试出现子任务启动失败，被安全拦截；再次完整通过。启动失败尚不能保证完全消除，遇到时可手动重试或关闭子智能体模式。
- 本次没有拿用户电影、登录文件或访问令牌做测试。

## English

Local-only beta: one official Codex session delegates up to 750 cues as primary 150 + two children of 300 each. Child results are collected directly from official JSONL events, validated and checkpointed independently. Only missing or invalid cues are repaired. Primary and children explicitly use low effort in this experimental mode; ordinary batches still support no extra reasoning.

Delegation adds overhead and does not guarantee faster translation. The primary output schema is not a guarantee of schema enforcement on child responses. Local validation remains mandatory. Quota/auth/service failures stop the job without account, model or API fallback. No authentication files or browser cookies are read by Sub Buddy. This unsigned-for-distribution, unnotarized Universal build is for local testing, not a stable-channel release.
